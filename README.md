# Examen de Conocimientos — IRCA

App web para aplicar los exámenes de conocimiento (Etapa 1 · Refrigeración y Etapa 2 · Aire Acondicionado).

- El alumno pone su **nombre**, contesta y al darle **guardar** ve su **nota al instante**.
- El instructor ve el **panel** con el reporte de notas.
- Backend: **Supabase** (gratis). La clave de respuestas vive **solo en el servidor** (no se puede ver inspeccionando el código).
